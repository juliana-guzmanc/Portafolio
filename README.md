# Portafolio — Juliana Guzmán · Analista de Datos

Portafolio personal (una sola página, HTML/CSS/JS, sin dependencias).

## Publicar en Vercel
1. Sube este repo a GitHub.
2. En vercel.com → Add New → Project → importa el repo.
3. Framework Preset: **Other**. Sin build command. Output: raíz del repo.
4. Deploy. Vercel sirve `index.html` automáticamente.

Carpeta `img/` contiene todas las imágenes del sitio.
